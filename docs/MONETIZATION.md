# API-Led Growth & Revenue

The API is the wedge; the tiers are the meter. The free read path is generous enough to
go viral; authenticated writes and monitoring meter by scans, frameworks, seats, and
private repos. Expansion is usage-based as a program grows — never a paywall on proof.

## Tiers

| Tier | Price | What unlocks |
| --- | --- | --- |
| Bronze | Free | Public repos, the Action on every push, standard frameworks, public Trust Profile + badge, one-link-no-login reads. Fuels the flywheel; stays genuinely useful. |
| Silver | $150/yr | Private repos, expanded frameworks, Slack/Discord drift webhooks, questionnaire auto-answer, more watched vendors. |
| Gold | $250/yr | Deep multi-pillar verification, EU AI Act conformity, priority delivery, unlimited seats/campaigns, Score Planner. |
| Enterprise | Custom | SSO, continuous monitoring at scale, custom frameworks, audit archive, SLA. |

## Usage hooks, by pillar

- PROTECT meters on scan volume, frameworks, and private repos. A vendor's own program
  growth is the upsell — more systems witnessed, more monitoring.
- PROVE converts on questionnaire auto-answer and evidence export: the features that
  turn a security review from days into minutes.
- GROW is the demand engine. `profile.viewed` and `profile.requested` become
  Marketplace Leads; buyer intent on your profile is the strongest expansion signal you
  have, and the cheapest pipeline Trooth can source.

## Self-serve onboarding

A free Bronze key at signup, no card. Five-line GitHub Action in existing CI. The CLI
and VS Code extension keep Trooth in the daily loop. The open-source verifier removes
lock-in fear. Time-to-first-witnessed-control is the activation metric that matters.

## Viral loops (each tied to a shipped surface)

Badge embed · pull-request Trust Score comment · Marketplace listing · buyer-invite
(`profile.requested`) · shareable scan report · open verifier SDK · OG scorecard shares.
Growth comes from the loops, not ad spend.

## Guardrails

Witnessed is not attested and never certified. No fabricated numbers. Honest
"coming soon" for anything not live; scaffold mode degrades to `pending`, never a false
pass. The free tier stays useful, because a hollow free tier starves the flywheel.
