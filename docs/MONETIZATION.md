# Pricing

The Trooth Network is Trooth's only product, and it is free. There is no paid plan,
no subscription, no card on file and nothing to buy: no tiers, no seats, no metered
usage and no paid features. Publishing a record and reading one cost nothing, and
paying Trooth cannot change what a record shows.

The public reads in the published contracts
([trooth.co/openapi.json](https://trooth.co/openapi.json) and
[trooth.co/openapi.yaml](https://trooth.co/openapi.yaml)) need no key. Where an
operation on `api.trooth.co` takes a Bearer token, the token is a session token or
an API key created from the company's workspace, and neither comes with a plan.

Use of the API is governed by the [Terms of Service](https://trooth.co/terms).
